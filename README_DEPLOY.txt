CARE CLEAN WEBSITE - NETLIFY DEPLOYMENT

This version has no Supabase dependency. The quote form uses Netlify Forms.

Upload all files and folders in this directory to the root of your GitHub repository.
Make sure src and public appear as folders at the top level in GitHub.

Netlify settings:
Build command: npm run build
Publish directory: dist

After GitHub finishes uploading, Netlify should redeploy automatically.
You can view quote submissions in Netlify under Forms.
